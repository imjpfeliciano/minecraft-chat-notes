# Screenshot checklist (gallery)

Capture these in the Fabric **1.21.11** `runClient` (or a real install with the mod). Prefer **1920×1080** (or 16:9), UI readable, no personal server IPs in the HUD if you care about privacy.

Save each file under `media/screenshots/` using the **exact filename** below so the [README](../../README.md) gallery lights up automatically.

| # | Filename | What to show | Tips |
|---|----------|--------------|------|
| 01 | `01-notes-list.png` | Main **Chat Notes** screen with several notes, coloured `&`-code previews, and at least one **group badge** | Best “hero” shot. Use Spanish or English UI depending on your listing language. |
| 02 | `02-search-and-filter.png` | Same screen with **search** text typed and/or a **group filter** selected (not “All”) | Shows that the library is browsable. |
| 03 | `03-note-editor.png` | **Edit / New note** screen: title, group picker, message with `&` codes, char counter, coloured preview | Paste a real shop-ad style message. |
| 04 | `04-use-in-chat.gif` | After **Use**: vanilla chat open with the note **pre-filled** (not sent) | GIF preferred so the Use → chat flow is clear; a PNG still works if you rename and update the README. |
| 05 | `05-groups-screen.png` | **Groups** screen with 2+ folders, note counts, accent rows, default ★ badge if set | Show the polished groups UI. |
| 06 | `06-copy-clipboard.png` | Optional: notes screen right after **Copy** (“Copied to clipboard”) **or** an external paste of the exact `&` text | Proves byte-for-byte copy; external paste is strongest. |

### Capture tips

1. Fill the list with 3–5 realistic notes (titles + coloured previews).
2. Hide debug HUD (`F3`) unless you want a tech look.
3. Singleplayer is fine; the mod is client-only and storage is global.
4. Keep a consistent window size across shots.
5. Do not include real passwords, tokens, or private coords if you post publicly.
